## RetroCase v0.1.1 Prototype

**Android 6.0+ · 日本語 / 繁體中文 / English / 简体中文**

Play the independent demo **The Missing Notebook**, switch languages in-game, and continue from your last auto-save. You can also import a four-language JSON case.

日本語｜オリジナル体験シナリオ「消えた手帳」を収録。プレイ中の言語切り替え、自動保存、JSONシナリオの読み込みに対応しています。

繁體中文｜內建獨立試玩案件「消失的筆記本」，支援遊戲內切換語言、自動存檔及匯入 JSON 案件。

**Original game data is not included. / 原作のゲームデータは未収録です。 / 尚未收錄原版遊戲資料。**

Download the APK below and open it on Android. This build uses a prototype signing certificate. Updating an existing installation requires a matching certificate. The SHA-256 file accompanies the APK for download verification.
